## quem sou

Sou o **Kauê** (a.k.a. **kyxen**), desenvolvedor de **Praia Grande/SP**. Python é a
minha linguagem principal, mas também escrevo TypeScript e JavaScript quando a
ocasião pede. Uso **Linux** no dia a dia e acredito que a linha de comando é o
jeito mais honesto de conversar com uma máquina.

O que eu construo segue uma regra simples: **simples, rápido e prático**. Nada
de exagero — só o que resolve o problema e não atrapalha ninguém.

## o que eu faço

- **Automação** — scripts e ferramentas CLI que fazem o trabalho chato sozinho
- **Backend** — APIs e serviços diretos, sem mistério
- **Eficiência** — performance e minimalismo antes de qualquer modismo
- **Frontend** — interfaces limpas com HTML, CSS e JS quando precisam existir
